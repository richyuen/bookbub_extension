ICON GENERATION

The PNGs in this folder are current:
  icon16.png   - 16 x 16   (toolbar)
  icon48.png   - 48 x 48   (extensions page)
  icon128.png  - 128 x 128 (installation / store)

The design is a green rounded square with a white open book and an amber
check badge. It does not use BookBub or Amazon marks.

TO REGENERATE:

1. Open "generate_icons.html" in any browser.
2. Click "Download All Icons".
3. Move the downloaded PNGs into this folder, replacing the existing files.
4. The 300 x 300 download is the Partner Center store logo, not a manifest icon.
5. Reload the extension in edge://extensions/.

You do not need an image editor.
